# Gnuvil 스마트미러 사용 설명서

동아리방 컴퓨터 한 대가 **스마트미러 + 음악 재생기** 역할을 합니다.
YouTube로 노래를 틀면 거울에 곡 정보·앨범 커버·소리 막대·자막이 저절로 나옵니다.

> 이 설명서와 바로가기는 **문서 › Gnuvil 스마트미러** 폴더에 있습니다.

---

## 화면 구성

| 화면 | 역할 |
|---|---|
| **세로 모니터 (거울)** | 스마트미러. 손대지 않아도 됩니다. |
| **가로 모니터 (LG)** | 평소에 쓰는 화면. 여기서 YouTube를 틀고 영상을 봅니다. |
| **스피커** | 컴퓨터 뒤 AUX 단자에 연결되어 있습니다. |

거울에는 이런 정보가 나옵니다.

```
GNUVIL Smart Mirror            BUS
23:42                          1500-2 · 에버랜드행   4분 · 23분
10월 28일 수요일
용인시  5.6°



        ▂▃▅▇▅▃▂▃▅▆▅▃   ← 소리 막대
  [커버]  재생 중
          곡 제목
          아티스트
          ━━━━━━━━──────  ← 재생 위치
          지금 나오는 자막
```

---

## 음악 틀기

1. **Microsoft Edge**를 엽니다. (자막은 Edge에서만 나옵니다.)
2. YouTube에서 노래를 틉니다.
3. 몇 초 안에 거울 아래쪽에 **곡 제목 · 아티스트 · 커버 · 재생 위치**가 나옵니다.
4. 영상을 크게 보고 싶으면 LG 모니터에서 전체화면(`F` 키)으로 보면 됩니다.

- 일시정지하거나 창을 닫으면 거울에 **"현재 재생 중인 음악이 없습니다"**가 나옵니다.
- 앨범 그림은 음원 사이트에서 **같은 곡이 확인될 때만** 쓰고, 아니면 YouTube 썸네일을 보여 줍니다.
- 커버곡(제목에 Cover가 있는 영상)은 부른 사람을 가수로, 영상 썸네일을 그림으로 보여 줍니다.
- 제목 형식이 특이하면 곡 제목이 조금 어색하게 나올 수 있습니다.

### 자막(가사) 보기

YouTube 플레이어 오른쪽 아래의 **CC(자막) 버튼**을 켜면, 거울의 재생 위치 아래에 자막이 같이 나옵니다.
한 번 켜 두면 다음 영상에도 그대로 켜져 있습니다. 자막이 없는 영상은 아무것도 나오지 않습니다.

## 켜고 끄기

컴퓨터를 켜고 로그인하면 **저절로** 스마트미러가 켜집니다.
켜자마자 바로 뜨지는 않고 **1~2분쯤** 걸립니다. 이 컴퓨터는 하드디스크라 부팅 직후가 느립니다.

손으로 다시 켜야 할 때는 **문서 › Gnuvil 스마트미러** 폴더의 바로가기를 더블클릭하세요.

| 바로가기 | 이럴 때 |
|---|---|
| **스마트미러 다시 시작** | 화면이 멈췄거나, 정보가 안 바뀌거나, 뭔가 이상할 때 (대부분 이걸로 해결됩니다) |
| **스마트미러 켜기** | 꺼 두었던 걸 다시 켤 때 |
| **스마트미러 끄기** | 잠시 꺼 두고 싶을 때 |
| **로그 폴더** | 문제가 계속될 때 관리자에게 보여 줄 기록 |
| **스마트미러 프로그램 폴더** | 프로그램이 들어 있는 곳 (관리자용) |

바로가기를 누르면 화면이 뜨기까지 **30초쯤** 걸립니다.

## 이럴 땐 이렇게

| 증상 | 해결 |
|---|---|
| 거울이 까맣거나 아무것도 안 나옴 | 로그인 후 2분 기다리기 → 그래도 안 되면 **스마트미러 다시 시작** |
| 노래를 틀었는데 곡 정보가 안 나옴 | Edge(또는 Chrome)로 틀었는지 확인. 작업 표시줄 소리 아이콘 옆 미디어 창에 곡이 보이는지 확인 → **스마트미러 다시 시작** |
| 자막이 안 나옴 | YouTube에서 **CC 버튼**을 켰는지, **Edge**로 틀었는지 확인. 그래도 안 되면 YouTube 탭 새로고침 |
| 소리 막대가 안 움직임 / 소리가 안 남 | 작업 표시줄 소리 아이콘 → 출력 장치가 **스피커**로 되어 있는지 확인 |
| 거울에 "버스 API 키 필요" | 버스 키가 빠졌습니다. 관리자에게 알려 주세요. |
| 거울이 가로 모니터에 떠 버림 | 모니터 케이블이 바뀌었을 수 있습니다. 관리자에게 알려 주세요. |
| 소리가 거울 모니터에서 남 | 소리 출력 장치가 모니터(BIT-B1743H)로 바뀐 것입니다. **스피커**로 바꿔 주세요. |

---

## 지켜 주세요

- 소리 설정의 **출력 장치는 "스피커"** 그대로 두세요. 바꾸면 소리 막대가 멈춥니다.
- **모니터 케이블을 바꿔 꽂거나** 디스플레이 설정을 바꾸지 마세요. 거울 위치가 틀어집니다.
- Edge의 **"Gnuvil Mirror Captions" 확장**을 끄거나 지우지 마세요. 자막이 이걸로 나옵니다.
  Edge가 "개발자 모드 확장을 끄시겠습니까?"라고 물으면 **유지**를 누르세요.
- 동아리방의 **라즈베리파이는 꺼 두세요.** 같은 버스 키를 쓰면 하루 사용량을 넘을 수 있습니다.

## 관리자용

- 프로그램: `C:\gnuvil\gnuvil-smartmirror` (GitHub `gnuvil/gnuvil-smartmirror`), MagicMirror: `C:\gnuvil\MagicMirror`
- 기술 문서: 프로그램 폴더의 `windows\README.md`
- 로그: `%LOCALAPPDATA%\gnuvil\logs` (`now-playing.log`, `magicmirror.log`)
- 자동 실행: 작업 스케줄러의 **Gnuvil Now Playing**, **Gnuvil MagicMirror** (로그온 시 실행, 꺼지면 1분 뒤 다시 실행)
- 버스 키: Windows **사용자 환경변수 `GBIS_API_KEY`** (`Win + R` → `rundll32 sysdm.cpl,EditEnvironmentVariables`). 파일이나 Git에는 넣지 않습니다.
- 업데이트: 프로그램 폴더에서 `git pull` → **스마트미러 다시 시작**. 도우미 소스(`windows\helpers`)가 바뀌었으면 먼저 **스마트미러 끄기** → `windows\build-helpers.ps1` 실행.
- 바로가기와 이 설명서를 다시 만들려면: `powershell -ExecutionPolicy Bypass -File windows\install-autostart.ps1`
