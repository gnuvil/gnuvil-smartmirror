# MMM-GnuvilCafeteria

한국외대 [글로벌캠퍼스 식당 페이지](https://www.hufs.ac.kr/hufs/11319/subview.do)의 **한그릇 식당**, **외대한상 식당**, **HufsDorm 식당** 메뉴를 표시합니다.

공개 문서화된 학식 API는 확인되지 않았습니다. 공식 페이지의 `JW_cafeteria_basic/js/view.js`는 `/cafeteria/hufs/2/getMenu.do`에 식당 ID와 주간 날짜를 POST하고, 응답으로 받은 HTML 표를 화면에 넣습니다. 모듈은 동일한 공개 요청을 서버에서 식당별로 한 번씩 호출하고, 오늘 날짜 열의 메뉴만 읽습니다. 식당 ID는 각각 `h203`, `h202`, `h205`입니다. 홈페이지 내부 인터페이스이므로 사이트 구조가 바뀌면 파서를 수정해야 합니다.

기본 조회 주기는 4시간입니다. 날짜가 바뀌면 30분 안에 다시 조회하고, 일부 식당 조회가 실패하면 한 시간 간격으로 재시도합니다. 같은 날짜에 마지막으로 읽은 메뉴는 유지합니다. 빈 메뉴, 휴무, 연휴는 `오늘 메뉴 없음`으로 표시합니다. 세 식당 모두 항상 표시하며, 메뉴가 여럿이면 현재 시간에 가까운 식사 최대 두 가지를 보여줍니다. 각 식사의 첫 네 메뉴 항목을 표시하고 나머지 개수를 덧붙입니다.

`config/config.js`에서 `refreshInterval`을 조정할 수 있으며 최소 1시간입니다. API 키나 추가 npm 패키지는 필요하지 않습니다.

검증: 이 디렉터리에서 `node --test`를 실행합니다. 실제 사이트 요청은 날짜에 따라 메뉴가 없을 수 있습니다.
