# MMM-GnuvilTimeFormat

화면에 그리는 것 없이 12시간제 시각 표기를 고칩니다.

- 오전/오후를 `AM`/`PM`으로 씁니다. 화면 언어(`language: "ko"`)는 그대로 두고 moment의 ko 로케일에서 오전/오후 표기만 바꾸므로 시계와 시간별 날씨 예보에 함께 적용됩니다.
- 시계의 시가 한 자리면 `03:45`처럼 앞에 0을 붙입니다. 시계 모듈은 시를 `"h"` 형식으로 따로 만들므로 moment의 `format("h")`만 `"hh"`로 바꿉니다. `"h:mm A"` 같은 다른 형식(시간별 예보의 `4:00 PM`)은 그대로입니다.

moment는 MagicMirror가 모듈 파일보다 나중에 읽으므로 `start()`에서 바꿉니다. `config.js`에서 시계보다 앞에 두어야 시계가 처음 그려질 때부터 적용됩니다. `position`은 지정하지 않습니다.

## 검증

이 디렉터리에서 `node --test`를 실행합니다.
